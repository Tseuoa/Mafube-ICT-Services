# Mafube ICT Services — Uniform Technology Background Update

This update makes the homepage and Mission, Vision, Values, and Executive pages use the same technology banner image as the top of the homepage. Page sections use dark translucent overlays rather than large white backgrounds, while individual cards can remain light for readable content.

## Files to upload
Upload `index.html`, `mission.html`, `vision.html`, `values.html`, `executive.html`, and `mafube-shared.css` to the root of the Mafube ICT Services GitHub Pages repository. Keep the existing `assets/images/Banner.jpeg`, logo files, `styles.css`, `script.js`, and other assets in place.

The background image is referenced as `assets/images/Banner.jpeg`, matching the homepage banner. Do not move or rename that image unless you also update the image path in `mafube-shared.css`.

The database folder is included as a starter for future growth; it does not become live until a database project and secure backend/API are configured.
