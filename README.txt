MAFUBE ICT SERVICES — MODERN WEBSITE
====================================

Files
-----
index.html   Main responsive website
styles.css   Corporate styling and responsive layout
script.js    Mobile navigation

How to use
----------
1. Extract the ZIP.
2. Open index.html in Chrome to preview.
3. Upload all files to your web host's public_html/www folder.
4. Point www.mafubeservices.co.za to the hosting account.

Notes
-----
- The site retains useful service themes from the supplied legacy page: IP Telephony,
  Video Conferencing, Call Centre Solutions, Instant Messaging, Voice Recordings,
  Email/Fax/SMS, Voice Mail, Presence and Telephony Management.
- Contact details are configured for Mafube ICT Services.
- The enquiry form currently opens the visitor's email client using mailto.
  For production, connect it to a server-side form handler or email service.
- The original site referenced local image files that were not included with the
  uploaded HTML. This rebuild therefore uses CSS-based visuals rather than inventing
  or hotlinking those missing assets.
